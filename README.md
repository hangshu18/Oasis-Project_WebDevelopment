# 🔒 Login Authentication System

A simple and responsive Login Authentication System built using **HTML, CSS, and JavaScript** as part of the **Oasis Infobyte Web Development Internship (Level 2 - Task 4)**.

---

## 📌 Project Overview

This project demonstrates a basic authentication workflow where users can:
* Register a new account
* Login using registered credentials
* Access a protected page after successful authentication
* Logout securely
* Store user information using the browser's Local Storage

The project is designed to help understand the fundamentals of user authentication and frontend web development.

How It Works
​1. User Registration
​User enters an email and password.
​Data is stored securely in the browser's Local Storage.
​2. User Login
​Credentials entered by the user are compared with the stored credentials.
​If valid, the user is redirected to the secure page.
​3. Secure Page Access
​Only authenticated users can access the secure page.
​Unauthorized users are automatically redirected back to the login page.
​4. Logout
​Removes the active authentication status.
​Redirects the user back to the login page.
